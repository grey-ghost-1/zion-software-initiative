# ADR 0003: Serve initiative and portfolio audiences equally

- **Status:** Accepted
- **Date:** 2026-09-01

## Context

Zion must explain proposed social-impact work to general readers while giving
recruiters concrete evidence of entry-level full-stack/backend engineering.

## Decision

Use one calm, accessible information architecture. Each future case study should
separate the public-interest problem, current product status, engineering
decisions, evidence, and limitations. Neither audience is hidden behind a
separate brand.

## Consequences

Technical depth remains available without overstating social outcomes. Content
requires plain-language summaries and links to inspectable implementation proof.
