# Harbor privacy and safety note

Harbor is a synthetic software demonstration. Its seed records describe
fictional resources, coarse zones, capacities, request codes, and volunteer
availability. They are not safe containers for real casework.

## Data minimization

The request API accepts only a patterned demo reference, category, coarse zone,
quantity from 1–8, controlled eligibility, a step-free requirement flag, and a
time classification. It has no unrestricted text field and no field for names,
contact details, precise addresses, confidential sites, medical or disability
details, immigration/benefit data, minors, or protected traits.

Public demo responses omit account identity and raw audit actor IDs. Volunteers
receive only assigned synthetic plan fields. Organization membership and roles
are resolved server-side.

## Decision and capacity safety

Matching is advisory and deterministic. The API explains score components,
rejections, and uncertainty; it never assigns automatically. Missing, stale,
unknown, closed, and insufficient capacity cannot be approved. Coordinator
approval atomically reserves capacity, and fulfillment consumes an existing
reservation.

## Out of scope

No live FEMA/OpenFEMA feed, map, geocoding, notification, dispatch, background
queue, model call, real partner workflow, or deployment exists. Before any real
data or operations, conduct partner-led requirements work, a data-protection
impact assessment, abuse review, retention/deletion design, incident planning,
and accessibility testing with affected stakeholders.
